# 碧蓝航线建造模拟器

Koishi 插件，模拟轻型、重型和特型建造，记录建造结果并统计收藏率。

## 安装

```sh
yarn add koishi-plugin-azur-lane-building
```

在 Koishi 中启用，并安装 `database` 与 `puppeteer` 服务。

## 指令

| 指令 | 说明 |
| --- | --- |
| `alb.每日魔方` | 领取每日魔方 |
| `alb.抽轻型池 [次数]` | 进行轻型建造 |
| `alb.抽重型池 [次数]` | 进行重型建造 |
| `alb.抽特型池 [次数]` | 进行特型建造 |
| `alb.轻型池` / `alb.重型池` / `alb.特型池` | 查看对应池内容与出货率 |
| `alb.建造记录` | 查看个人建造统计 |
| `alb.收藏率排行榜` | 查看收藏率排行 |

| 稀有度 | 轻型 | 重型 / 特型 |
| --- | ---: | ---: |
| 海上传奇 | — | 1.2% |
| 超稀有 | 7% | 7% |
| 精锐 | 12% | 12% |
| 稀有 | 26% | 51% |
| 普通 | 55% | 28.8% |
