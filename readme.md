Koishi 的碧蓝航线建造模拟器插件。

## 使用

`alb.每日魔方` 领取魔方，`alb.抽轻型池 [次数]` 开始建造。

## 指令

| 指令 | 说明 |
| --- | --- |
| `alb.每日魔方` | 每日领取魔方 |
| `alb.抽轻型池 / 抽重型池 / 抽特型池 [次数]` | 建造 |
| `alb.轻型池 / 重型池 / 特型池` | 查看池内容与出货率 |
| `alb.抽卡记录` | 个人建造统计 |
| `alb.收藏率排行榜` | 收藏率榜 |

## 出货率

| 稀有度 | 轻型 | 重型 / 特型 |
| --- | --- | --- |
| 海上传奇 | — | 1.2% |
| 超稀有 | 7% | 7% |
| 精锐 | 12% | 12% |
| 稀有 | 26% | 51% |
| 普通 | 55% | 28.8% |
